# Lingo Bingo

---

### 🌟 Purpose
**Lingo Bingo** is a winter-themed language-learning platform designed to help users learn Arabic vocabulary in an engaging and interactive way. It’s perfect for language enthusiasts aiming to enhance their skills through lessons, tutorials, and fun challenges. 

---

### 🌐 Live URL
[Lingo Bingo Live App](https://lingo-bingo-aecbd.web.app/lessons/4)

---

### 🚀 Key Features
1. **Interactive Navigation Bar**:  
   - Animated navbar icons for an engaging UI.  
   - Displays a **Login** button for guests and switches to a **Logout** button along with the user's profile picture upon login.

2. **Dynamic Banner**:  
   - The homepage features an auto-switching banner for an eye-catching experience.

3. **Mission and Success Sections**:  
   - "Our Mission" highlights the app's purpose.  
   - "Success Ratings" section features animations to enhance visual appeal.

4. **Quick Access to Learning**:  
   - Click the **Join the Challenge** button to navigate directly to the "Start Learning" page.  
   - Lessons feature Arabic words with detailed explanations.

5. **Lesson Pages**:  
   - Each lesson contains words in Arabic.  
   - Users can:  
     - **Listen** to the pronunciation of words.  
     - Click **When to Say** to see usage examples and contexts.

6. **Tutorials Page**:  
   - Includes videos on learning Arabic for additional resources.

7. **Profile Management**:  
   - View your profile information on the **My Profile** page.  
   - Update your profile name and image by clicking the **Update** button, which redirects to the Update Profile page.

8. **Minimalistic Authentication Pages**:  
   - Clean and minimal design for login and signup.

9. **About Us Page**:  
   - Provides details about Myself, my project's info, skills.

### 📦 NPM Packages Used
The following npm packages were utilized in developing **Lingo Bingo**:
- **React Router DOM**: For routing and navigation.  
- **Tailwind CSS**: For modern and responsive styling.  
- **DaisyUI**: Tailwind component library for pre-designed elements.  
- **React-Countup**: For show a counting numbers of success ratings.
- **Animate.css**: For animations like navbar icons .  
- **React Toastify**: To display notifications and alerts.  
- **React Icons**: For using icons throughout the application.
